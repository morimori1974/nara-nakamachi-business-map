# 奈良市中町周辺 事業所マップ

奈良県奈良市中町5066-1を中心とする半径3km圏内の中小企業・工場／店舗／病院／老人ホーム・介護施設（計281件）を地図上にプロットした静的サイトです。

- `index.html` : 地図本体（Leaflet + OpenStreetMap）
- `data.json` : 事業所データ（名称・住所・事業内容・HP・出典・距離・緯度経度）

## 注意事項

このリポジトリおよびGitHub Pagesで公開されるサイトは、閲覧制限をかけるまでは URL を知っていれば誰でも閲覧できる状態になります。Cloudflare Workers 経由の Basic 認証を設定するまでは、この URL を第三者と共有しないでください。
